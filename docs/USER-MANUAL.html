Velvet Chords

User manual for version 1.1. A chord-pad instrument for MPC OS.

Velvet Chords turns each pad into a full chord. It plays through its own built-in sounds, or it sends its chords out as MIDI to another instrument. It has 64 pads in four banks, a Smart Scale mode for melodies and basslines that fit the chord you are playing, rhythm patterns, arpeggios, a progression player, 900 factory presets, and tools for importing chords from MIDI files and analysing audio.

1. Getting started

  1. Make a new plugin track and choose Velvet Chords from the instrument plugins.
  2. Open the Play page. Tap a pad on the screen, or hit the matching MPC pad. Each pad plays its whole chord.
  3. Pick a mode at the top: Chords, Types, Custom, Chrom notes, Scale notes or Chrom chords. The pads change at once.
  4. Choose a key on the keyboard on the right. The chords follow it.
  5. Choose a bank (A, B, C or D, top right). Each bank shows 16 of the 64 pads.

The top left of the Play page shows the factory preset in use, with prev and next buttons. The band across the top shows the notes of the current scale in the current key.

2. Installing

Velvet Chords installs on a first-generation MPC OS standalone device (MPC X, Live, Live II, One, Key 61 or Force). The installer refuses other devices. Installing it this way needs root shell access (SSH) to the device, which stock MPC OS does not offer. This is unofficial and not supported by Akai, so back up first.

Installing from Termius

  1. Download VelvetChords-MPC from the build page in a browser. It is a zip that contains another zip.
  2. Connect to the MPC in Termius (its IP address, port 22, user root), then open SFTP and upload the downloaded zip to /tmp.
  3. In the Termius terminal, unzip it twice: 
    cd /tmp && unzip -o VelvetChords-MPC.zip && unzip -o VelvetChords-1.0.0.zip
    If unzip is not found, use busybox unzip instead. The inner zip is named 1.0.0 because of how it is built, but it contains the current version.
  4. Save your MPC project. The installer stops MPC, so nothing you have not saved will survive.
  5. Run the installer and answer y when asked: 
    sh /tmp/VelvetChords-1.0.0/install.sh
    It copies the plugin, the screen skin and the sound files, backs up your settings, and restarts MPC.
  6. Add a track, choose Velvet Chords from the instrument plugins, and check that the screen has six pages.
If MPC starts with default settings after installing, restore the MPC.settings backup the installer made.

To upgrade, repeat the steps. The installer updates in place and keeps your projects and exports.

4. The Perform page

The sound and how the chords are played:

  • Sound: Electric piano, Rhodes, Wurlitzer, Bright Rhodes, Clavinet, Piano, Soft pad, Poly synth, Strings, Supersaw, Choir, Brass, Harp, Organ, Marimba, Vibraphone, Nylon guitar, Pluck, Music box, or Silent (MIDI out only).
  • Sound extra adds four more sounds: FM bell, Synth bass, Glass pad and Saw lead. Picking a sound from the Instrument grid turns them off again.
  • Reverb adds a room reverb to the built-in sound. It starts at 25%; set it to 0% for a dry sound.
  • Humanize makes each hit's velocity wander a little, so repeated hits don't sound identical. It is off at 0%.
  • Tone brightens or darkens every sound. Release sets how long a chord rings after you let go. Volume sets the level.
  • Velocity: linear, soft, hard or fixed response to how hard you hit a pad.
  • Strum (0 to 150 ms) spreads the chord notes out, and Strum dir sets up, down or alternate.
  • Arp and Arp rate run an arpeggio, synced to the MPC tempo. See also the Lanes page for four arpeggio lanes.
  • Inversion, Octave, Transpose (-12 to +12) and Voice lead (pads in a bank move smoothly from one to the next).
  • MIDI out and MIDI channel. See Sending chords to another instrument.
  • Pad 1 note and Learn pad 1: which incoming note is pad A01. See Troubleshooting.
  • Save progression and Export MIDI.

5. The Pattern page

Choose a rhythm and every chord you hold plays in that rhythm instead of a single hit. There are 15 presets (Sustain, Quarters, Neo-soul push, Slow jam, Gospel drive, Funk 16ths, Bass and stabs, Reggae skank, Caribbean 3-3-2, Dancehall, Afrobeats, Half-time and more).

  • The 16-step grid. Tap a cell to choose what the step does: Accent or Chord plays the whole chord (accent louder); Upper or Upper acc plays only the notes above the bass; Bass plays only the bass note; Tie holds the previous step; Rest is silence. Editing a preset saves it as your Custom pattern.
  • Step length sets the grid (1/8 to 1/32, with triplets). Swing pushes every second step late. Note length shortens each hit.
  • Timing: Follow MPC locks the pattern to the MPC's song position while the sequencer runs. Free starts it from the moment you hit the pad.
  • Pattern length (4, 8, 12 or 16 steps), Pattern chance (25, 50, 75 or 100%) and Pattern seed (1 to 4). The same seed always plays the same hits.
  • Send chords as MIDI with Off, To MPC, Virtual port or Both.
A pattern takes priority over the arpeggiator. A pattern you have chosen plays instead of the arpeggio. Presets do not change your pattern.

6. The Edit page

Changes the chord on any pad.

  1. Tap a chord key to select it.
  2. Set its root (on the keyboard), its bass note, its chord type, inversion and octave.
  3. Editing switches the mode to Custom, so you hear your change at once.

Copy to Custom copies whatever layout you are playing into the 64 custom pads, so you can start from it. Analyze sample and Clear progression are at the bottom (see Importing and analysing).

With Edit follows pad on, hitting a pad on the MPC selects it for editing in Custom mode.

8. The Lanes page

The sixth page holds the presets, the shift keys, the riff, the four arpeggio lanes and the note editor.

  • Four arp lanes run at the same time. Lane 1 is Arp, with its rate, octaves and transpose. Lanes 2 to 4 each have their own order, rate, octaves and transpose. Orders: Up, Down, Up-down, Random, Converge (outside in) and Diverge (inside out).
  • Riffs. A riff plays one of six patterns on the grid, such as Root and fifth, Octave bounce or Thirds run. Each of the 16 riff steps is a rest or an offset from the held chord's root, from -12 to +24 semitones.
  • Note editor. Edit note picks the whole chord or one of its notes; Edit note interval moves it by -12 to +24 semitones, or removes it.
  • Shift keys (on by default): the black keys in the octave below the pads act without playing a chord. C# moves the key down a semitone, D# up, F# to the previous scale, G# to the next scale, A# to the next inversion.

9. Modes: Chords, Types, Custom and the note modes

  • Chords builds the chords from the key and scale you choose, with the chord's roman numeral on each pad.
  • Types puts one chord type on each pad, all built on the key's root. Bank A has the basic types (major, minor, 7ths, sus, 9ths). Bank B has the extended ones (11ths, 13ths, altered). Banks C and D are the same as A and B, one octave higher. For example, with F as the root: bank A gives F, Fm, F7, Fmaj7, Fm7…
  • Custom plays your own 64 pads. Edits switch to this mode.
  • Chrom notes puts one note on each pad, every semitone from the key up (pad 1 is the key, pad 13 the key an octave higher). The Octave setting moves the whole layout.
  • Scale notes puts the notes of the chosen scale on the pads in pitch order, so a bank runs up the scale.
  • Chrom chords puts one chord root on every semitone from the key: bank A is major, B minor, C dominant 7th and D minor 7th. Changing the key moves every chord.

The note and chord modes remap at once when you change the key, scale or octave, even while the sequencer plays. A pad that is held when its notes change is released on the notes it started with.

To try Types: pick Types, set the key to F, and open bank A. Pad 1 should read F, pad 2 Fm and pad 3 F7. If the names don't change, the mode did not take.

10. Smart Scale pads

Set Smart Scale pads to Pads 9-16 and the bottom row of pads plays single notes that fit the chord you played last on the top row. Play a chord with one hand and a melody or bassline with the other, and nothing clashes. Smart pads only give notes that fit the chord, so they cannot play a wrong note.

  • Smart notes: Chord plays the chord's notes; Scale plays the chord's notes plus the rest of the scale, for passing notes; Bass plays the chord's notes low, starting on the slash-bass note for chords like Fmaj7/G.
  • Smart octave moves them up or down.
  • Smart map chooses the layout. Follow (the default) uses Smart notes and the chord. Relative walks the key's scale from the key root. Absolute walks the scale from C, so the notes stay put when you change key. Chromatic walks all twelve semitones.
  • Two copies: with a second Velvet Chords on another track set to Follow, its pads follow the chords of the first, live. Set it to Bass for a bassline, or Scale for a lead.

11. Presets

Velvet Chords has 900 factory presets: 90 genres, each with 10 variations. A preset sets the tone, voicing, strum, Smart Scale settings, key and scale of its genre. It never changes the instrument: the Sound you chose stays as it is. It leaves your pattern alone, and it never changes your custom pads.

  • Preset genre and Preset variation (Play page knobs): choose the genre first, then the variation.
  • Preset prev / next step through all 900 in order.
  • The MPC preset box lists Manual and all 900 presets. Choose one there to apply it.
  • Manual changes nothing and leaves your settings as they are.
  • A preset never replaces the Silent sound and never turns the arpeggio on.
  • Starred presets (Tools page): press Star preset on a preset you like. Prev star and Next star step through your stars.
  • Your presets (Tools page): choose one of four slots and press Save to keep your current settings, or Load to bring them back. A saved preset also keeps the pattern, arpeggio lanes, riff, bassline, harmony and progression. Your presets are stored with the project.
  • Export file and Import file share a saved preset as a plain text file, user-preset-N.vcpreset, in the Velvet Chords folder.

12. Progressions and progression play

  • Progression (Play page) fills pads 1 onward with a progression in the current key: I-V-vi-IV, ii-V-I, i-VI-III-VII, Andalusian, Axis, Pop I-IV, Neo-soul ii-V-I, or 12-bar blues. Pad 1 plays step 1, and so on. Off restores the normal layout.
  • Progression play plays the progression by itself while the host plays: one chord per bar, starting on each bar line. It assumes 4/4 and uses the host's tempo and position.
  • Harmony (Tools) adds a second voice to each smart-pad note, in the key's scale: third up, sixth up, third down or octave up.
  • Your own progressions: the 16 chords on bank A can be saved as one of four user progressions with Save progression (Perform page). Recall one with the progression control, which lists User 1 to 4.

13. Sending chords to another instrument

Velvet Chords can be a chord-and-pattern generator that plays another instrument. It sends its chords as MIDI and can stay silent itself.

  1. Track 1: Velvet Chords. On the Pattern page, set Built-in sound to Silent and Send chords as MIDI to Virtual port. The output is on channel 16 by default.
  2. Track 2: your instrument. On that track's MIDI input, choose the input Velvet Chords Out, channel 16, with monitoring on. Menu names differ between MPC OS versions.
  3. Select Track 1 and play the pads. Each pad sends its chord, or its pattern, to Track 2.

The MIDI port readout on the Pattern page shows whether the port opened. If the port does not appear as an input on Track 2, save the project and restart MPC with the plugin loaded so it rescans its MIDI ports.

Choose the routing carefully. Virtual port sends the chords only to a track whose input you set to Velvet Chords Out. To MPC and Both put the chords into the MPC's own MIDI routing, where any track set to all inputs can receive them and be cut off by a note-off. Leave MIDI out on Off unless you need the chords as MIDI.

MIDI channel (Pattern page) sets the output channel. The default is 16.

MIDI log (diagnostic)

On the Tools page, MIDI log writes every MIDI event Velvet Chords receives (I), sends (O) and gets from the host on start or stop (M) to Velvet Chords/MIDI log.txt. Each line has the time in seconds, the direction, and the three bytes in hex. Turn it on, reproduce the problem, turn it off, and send the file. The file keeps growing while the log is on.

14. Recording with Velvet Chords

  • Hold and Repeat change how long chords ring and how they retrigger. Hold is off by default.
  • Velvet Chords ignores MIDI All notes off and All sound off messages from the MPC, so a recording starting does not cut a chord that is ringing. Each pad still ends its own chord when you let go.
  • If an instrument track is cut out while you record drums and Virtual port is on, the cause is the routing on the MPC side. Record the chords on their own track first, or mute or disarm the instrument track while you record the drums.

15. Importing MIDI and analysing audio

Importing chords from a MIDI file

  1. Copy .mid files into the Velvet Chords/Import folder on the MPC's internal drive. The plugin creates the folder.
  2. On the Tools page, pick a file with Import file and press Load chords.
  3. Notes that start together become a chord. Each chord is named, and the chords go onto the pads in order, with the file's exact notes. Up to 64 chords, across banks A to D. Drum tracks are ignored.

Pads play → Layout goes back to your normal pads. Imported chords are saved with your project. Use Copy to Custom on the Edit page to change them.

Analysing a sample

  1. Put a WAV file in Velvet Chords/Analyze/. The installer and the first press of Analyze sample create the folder.
  2. The file can have any name. If there is no sample.wav, Velvet uses the first WAV in the folder.
  3. Accepted formats: 16-bit, 24-bit PCM and 32-bit float, mono or stereo. Up to 120 seconds is read.
  4. Choose a progression slot with Progression slot (Tools), then press Analyze sample (Edit page).
  5. Velvet estimates the chords, the key and how sure it is, and writes the chords into that slot in time order. Choose the slot on the Play page to play them.
A slot that already holds chords is never overwritten. Press Clear progression on the Edit page first. The analysis has been tested on generated audio with drums. It has not been tested on real recordings or on the MPC, so check the chords it finds.

17. Uninstalling

Run the uninstaller the same way as the installer:

sh /tmp/VelvetChords-1.0.0/uninstall.sh

It removes the plugin, its screen skin and its plugin-list entry, and restarts MPC. Your Velvet Chords folder, with your exports and analysed samples, is kept. Projects that used the plugin still open, without it.

18. Limits and what is untested

  • Velvet Chords is an unofficial plugin for MPC OS and is not supported by Akai.
  • The MIDI output routing to other instruments, the recording behaviour and the preset box have not been confirmed on every MPC model and OS version.
  • The audio analysis has not been tested on real recordings.
  • The Song data is kept in the source for reference only. Song mode is not on the screen. The song entries are unverified analyses, not transcriptions.
  • Velvet Chords doesn't record audio, export audio, or edit the sequencer.
