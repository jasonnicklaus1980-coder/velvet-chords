Notes use the MPC naming convention (MIDI 60 = C3). *Voicing* is the plugin's generated performance voicing (bass note + voice-led upper structure), not the voicing on the record. *Pad* is where the chord sits in Song mode (A01 = bank A, pad 1, bottom-left). Time signature 4/4 is assumed where not verified.
